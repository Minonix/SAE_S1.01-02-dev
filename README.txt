Pour compiler : make
Fonctionne pour les données jusqu'à 1000 sans autre commande.
Pour le 5000, si vous êtes sur linux, il faut exécuter la commande ulimit -s unlimited sur votre terminal
pour pouvoir lancer la commande.

L'exécutable sera nommé main.exe ou main.out en fonction de votre OS.
Il prend un unique parametre, le nom du fichier de trajets.
